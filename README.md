# Sakhli AI — макет ИИ-риэлтора для Тбилиси

Кликабельный прототип продукта: поиск квартир на естественном языке, каталог
объявлений, блог и раздел для инвесторов с расчётом доходности по каждому
объекту. Все квартиры, статьи и цифры — вымышленные данные для демонстрации.

Открыть: `index.html` в любом браузере (файл полностью самодостаточен —
никакого сервера или сборки не нужно).

## Что внутри

- **Поиск (`#search`)** — текстовое поле принимает запрос вида «квартира с
  видом на горы, у метро, для инвестиций, бюджет до $150 000». Скрипт
  разбирает запрос на критерии (район, бюджет, комнаты, цель аренды,
  особенности) и ранжирует каталог, показывая для каждого результата чипы
  с объяснением совпадения. Это клиентская имитация: в проде разбор запроса
  и подбор объектов будет делать модель Claude через API.
- **Объявления (`#listings`)** — карточки восьми квартир в разных районах
  Тбилиси (Ваке, Вера, Сабуртало, Мтацминда, Старый Тбилиси, Чугурети,
  Дигоми) с параметрами, тегами и ценой в $ и ₾.
- **Блог (`#blog`)** — редакционные материалы о районах и о том, как
  устроен ИИ-поиск.
- **Для инвесторов (`#investors`)** — сравнительная таблица по всем
  объектам и детальные карточки: доходность от долгосрочной и посуточной
  аренды (с переключателем), срок окупаемости и график прогнозируемой
  стоимости на горизонте 10 лет. Методика расчёта и её допущения — в
  плашке-дисклеймере над таблицей.

## Технологии

Один файл `index.html`: HTML + CSS-переменные (с поддержкой светлой и
тёмной темы) + ванильный JS, без сборки и зависимостей. Шрифты — Unbounded,
Source Serif 4 и IBM Plex Mono (Google Fonts).
