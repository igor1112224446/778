# RealtorAI — макет ИИ-риэлтора для Тбилиси

Кликабельный прототип продукта в стиле «Caucasian Modernity» — editorial
real-estate дизайн на пересечении архитектурного наследия Тбилиси и точной
алгоритмической эстетики: разговорный ИИ-поиск, каталог с AI-подбором,
инвестиционный калькулятор доходности, аналитика районов и панель агента
для добавления объектов. Все квартиры, статьи и цифры — вымышленные данные
для демонстрации.

Открыть: `index.html` в любом браузере (файл полностью самодостаточен —
никакого сервера или сборки не нужно).

## Что внутри

- **Разговорный ИИ-поиск + карта (`#search`, в стиле Яндекс.Недвижимости)** —
  двухпанельный модуль: слева чат, который сообщает, сколько объектов нашлось,
  даёт разбивку по типам квартир и по очереди уточняет цель (жизнь / инвестиции)
  и бюджет кликабельными вариантами ответа; справа — стилизованная карта Тбилиси
  с ценовыми метками и плашкой числа комнат. Клик по метке (или ответ в чате)
  открывает всплывающую карточку объекта: фото, цена, задаток, комиссия агента,
  итого к оплате, контакт агента с кнопкой «Показать телефон» (демо-номер).
  Карточку можно скрыть, сохранить в закладки или открыть в каталоге/калькуляторе.
  Свободный текст в поле ввода разбирается на критерии (район, бюджет, комнаты,
  цель, особенности) той же клиентской эвристикой — в проде это возьмёт на себя
  модель Claude через API.
- **Каталог (`#listings`)** — полный список объектов (включая добавленные через
  панель агента): карточки с районом, динамической плашкой (Cap Rate / рост
  цены / окупаемость), вердиктом ИИ, лентой из трёх метрик, кнопкой «На карте»
  (подсвечивает объект в модуле поиска) и сохранением в закладки. «Показать ещё»
  раскрывает остальные варианты.
- **Инвестиционный калькулятор (`#calculator`)** — выбор объекта, цена
  покупки и меблировка, переключатель модели монетизации (долгосрок /
  посуточно / гибрид), слайдер горизонта владения (1–10 лет), налог и
  комиссия управления. Справа — живые метрики (денежный поток, IRR,
  окупаемость), график капитализации с накопленной арендой и текстовый
  вердикт ИИ с рекомендацией модели монетизации.
- **Аналитика районов (`#analytics`)** — агрегированные показатели по
  районам каталога (цена за м², Cap Rate, тренд цены) плюс сравнительная
  карточка рынков.
- **Панель агента (`#admin`)** — форма добавления объекта (название, район,
  комнаты, площадь, цена, описание, теги-особенности, допущения для
  доходности). Новый объект сразу появляется в поиске, калькуляторе и
  аналитике; хранится в `localStorage` браузера — реального бэкенда в
  прототипе нет.
- **Валюта и закладки** — переключатель USD/₾ GEL в шапке меняет акцент
  цены по всему сайту; иконка закладок сохраняет понравившиеся объекты
  (тоже в `localStorage`).

## Технологии

Один файл `index.html`: HTML + CSS-переменные (с поддержкой светлой и
тёмной темы) + ванильный JS, без сборки и зависимостей. Шрифты — Epilogue,
Manrope, JetBrains Mono и иконки Material Symbols Outlined (Google Fonts).
