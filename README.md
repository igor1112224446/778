# RealtorAI — макет ИИ-риэлтора для Тбилиси

Кликабельный прототип продукта в стиле «Caucasian Modernity» — editorial
real-estate дизайн на пересечении архитектурного наследия Тбилиси и точной
алгоритмической эстетики. Интерфейс построен как приложение с боковой
панелью в стиле Claude / ChatGPT: разговорный ИИ-поиск, каталог с
AI-подбором, инвестиционный калькулятор доходности, аналитика районов и
панель агента для добавления объектов. Все квартиры, статьи и цифры —
вымышленные данные для демонстрации.

Открыть: `index.html` в любом браузере (файл полностью самодостаточен —
никакого сервера или сборки не нужно).

## Что внутри

- **Боковая панель (слева)** — как в Claude/ChatGPT: кнопка «Новый чат»,
  фильтры каталога **«Аренда»** (весь каталог с расчётной арендой в месяц),
  **«Новостройки»**, **«Вторичка»** (по тегу «новостройка» в объекте) и
  **«Избранное»** (объекты, отмеченные значком закладки), блок «История
  чатов» с прошлыми запросами (клик восстанавливает диалог) и переключатели
  вида: ИИ-поиск и каталог / Калькулятор инвестора / Аналитика районов /
  Панель агента, плюс переключатель валюты USD/₾ GEL. На мобильных экранах
  панель открывается кнопкой-гамбургером поверх контента.
- **Разговорный ИИ-поиск (`#search`)** — чат в духе ChatGPT: сообщает,
  сколько объектов нашлось, даёт разбивку по типам квартир и по очереди
  уточняет цель (жизнь / инвестиции) и бюджет кликабельными вариантами
  ответа. Свободный текст в поле ввода разбирается на критерии (район,
  бюджет, комнаты, цель, особенности) той же клиентской эвристикой — в
  проде это возьмёт на себя модель Claude через API.
- **Подборка / каталог (`#listings`)** — карточки под чатом отражают текущий
  фильтр (категория сайдбара, история или результат чата): район, цена (или
  расчётная аренда в месяц), вердикт ИИ, лента из трёх метрик (аренда/мес,
  рост за 3 года, окупаемость), кнопки «В калькулятор» и «Подробнее» —
  последняя открывает справа выезжающую карточку объекта: фото, цена,
  задаток, комиссия агента, итого к оплате, контакт агента с кнопкой
  «Показать телефон» (демо-номер). Карточку можно скрыть, сохранить в
  закладки или открыть в каталоге/калькуляторе. «Показать ещё» раскрывает
  остальные варианты.
- **Инвестиционный калькулятор (вид «Калькулятор инвестора»)** — выбор
  объекта, цена покупки и меблировка, переключатель модели монетизации
  (долгосрок / посуточно / гибрид), слайдер горизонта владения (1–10 лет),
  налог и комиссия управления. Справа — живые метрики (денежный поток, IRR,
  окупаемость), график капитализации с накопленной арендой и текстовый
  вердикт ИИ с рекомендацией модели монетизации.
- **Аналитика районов (вид «Аналитика районов»)** — агрегированные
  показатели по районам каталога (цена за м², Cap Rate, тренд цены) плюс
  сравнительная карточка рынков.
- **Панель агента (вид «Панель агента»)** — форма добавления объекта
  (название, район, комнаты, площадь, цена, описание, теги-особенности,
  допущения для доходности). Новый объект сразу появляется в поиске,
  калькуляторе и аналитике; хранится в `localStorage` браузера — реального
  бэкенда в прототипе нет.
- **Валюта и закладки** — переключатель USD/₾ GEL в сайдбаре меняет акцент
  цены по всему сайту; значок закладки на карточках сохраняет понравившиеся
  объекты (тоже в `localStorage`) и питает фильтр «Избранное».

## Технологии

Один файл `index.html`: HTML + CSS-переменные (с поддержкой светлой и
тёмной темы) + ванильный JS, без сборки и зависимостей. Шрифты — Epilogue,
Manrope, JetBrains Mono и иконки Material Symbols Outlined (Google Fonts).
