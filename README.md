# RealtorAI — макет ИИ-риэлтора для Тбилиси

Кликабельный прототип продукта: крупный ChatGPT-style поиск квартир на
естественном языке, каталог объявлений, блог, раздел для инвесторов с
расчётом доходности по каждому объекту и админ-панель для добавления новых
объявлений. Все квартиры, статьи и цифры — вымышленные данные для
демонстрации.

Открыть: `index.html` в любом браузере (файл полностью самодостаточен —
никакого сервера или сборки не нужно).

## Что внутри

- **Поиск (`#search`)** — крупное поле ввода в духе ChatGPT/Perplexity,
  главный акцент главной страницы. Принимает запрос вида «квартира с видом
  на горы, у метро, для инвестиций, бюджет до $150 000». Скрипт разбирает
  запрос на критерии (район, бюджет, комнаты, цель аренды, особенности) и
  ранжирует каталог, показывая для каждого результата чипы с объяснением
  совпадения. Это клиентская имитация: в проде разбор запроса и подбор
  объектов будет делать модель Claude через API.
- **Объявления (`#listings`)** — карточки квартир в разных районах Тбилиси
  (Ваке, Вера, Сабуртало, Мтацминда, Старый Тбилиси, Чугурети, Дигоми и др.)
  с параметрами, тегами и ценой в $ и ₾. Объекты, добавленные через
  админ-панель, помечаются флажком «Новое» и попадают сюда же.
- **Блог (`#blog`)** — редакционные материалы о районах и о том, как
  устроен ИИ-поиск.
- **Для инвесторов (`#investors`)** — сравнительная таблица по всем
  объектам и детальные карточки: доходность от долгосрочной и посуточной
  аренды (с переключателем), срок окупаемости и график прогнозируемой
  стоимости на горизонте 10 лет. Методика расчёта и её допущения — в
  плашке-дисклеймере над таблицей.
- **Панель агента (`#admin`)** — форма добавления нового объекта: название,
  район, комнаты, площадь, этаж, цена, свободное описание, особенности
  (чекбоксы-теги) и допущения для расчёта доходности (ставка аренды, тариф
  и загрузка посуточно, ожидаемый рост цены). Добавленный объект сразу
  появляется в объявлениях, поиске и у инвесторов и сохраняется в
  `localStorage` браузера — реального бэкенда в прототипе нет.

## Технологии

Один файл `index.html`: HTML + CSS-переменные (с поддержкой светлой и
тёмной темы) + ванильный JS, без сборки и зависимостей. Шрифты — Sora,
Manrope и JetBrains Mono (Google Fonts).
