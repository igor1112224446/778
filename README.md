# RealtorAI — макет ИИ-риэлтора для Тбилиси

Кликабельный прототип продукта в стиле «Caucasian Modernity» — editorial
real-estate дизайн на пересечении архитектурного наследия Тбилиси и точной
алгоритмической эстетики. Интерфейс построен как приложение с боковой
панелью в стиле Claude / ChatGPT: разговорный ИИ-поиск, каталог с
AI-подбором, инвестиционный калькулятор доходности, аналитика районов и
панель агента для добавления объектов. Все квартиры, статьи и цифры —
вымышленные данные для демонстрации.

Открыть: `index.html` в любом браузере (файл полностью самодостаточен —
никакого сервера или сборки не нужно).

## Что внутри

- **Боковая панель (слева)** — как в Claude/ChatGPT/Яндекс.Недвижимости:
  кнопка «Новый чат» (возвращает на стартовый экран), фильтры каталога
  **«Аренда»** (весь каталог с расчётной арендой в месяц), **«Новостройки»**,
  **«Вторичка»** (по тегу «новостройка» в объекте) и **«Избранное»**
  (объекты, отмеченные значком закладки) — каждый сразу открывает чат-режим
  с картой по этому фильтру; блок «История чатов» с прошлыми запросами (клик
  восстанавливает диалог); переключатели вида: ИИ-поиск и каталог /
  Калькулятор инвестора / Аналитика районов / Панель агента, плюс
  переключатель валюты USD/₾ GEL. На мобильных экранах панель открывается
  кнопкой-гамбургером поверх контента.
- **Стартовый экран («hello», вид «ИИ-поиск и каталог» по умолчанию)** — как
  на `realty.yandex.ru/ai/hello`: крупный заголовок, широкое поле ввода
  ChatGPT-стиля со стрелкой отправки, две подсказки-чипсы («Подобрать по
  анкете», «Новостройка с террасой у парка») и под ними — витрина карточек
  всего каталога (фото, цена, вердикт ИИ, три метрики, кнопки «В
  калькулятор» и «Подробнее»).
- **Разговорный ИИ-поиск + карта (чат-режим, в стиле Яндекс.Недвижимости)** —
  после отправки запроса, клика по фильтру сайдбара или пункту истории
  витрина сменяется двухпанельным модулем: слева чат (сообщает, сколько
  объектов нашлось, даёт разбивку по типам квартир, по очереди уточняет цель
  «для жизни / для инвестиций» и бюджет кликабельными вариантами ответа,
  внизу — поле свободного ввода); справа — стилизованная карта Тбилиси с
  ценовыми метками. Клик по метке открывает плавающую карточку объекта:
  фото, цена (или расчётная аренда/мес — для фильтра «Аренда»), задаток/залог,
  комиссия агента, итого к оплате, контакт агента с кнопкой «Показать
  телефон» (демо-номер). Карточку можно скрыть, сохранить в закладки,
  открыть в калькуляторе или вернуться в каталог. Свободный текст разбирается
  на критерии (район, бюджет, комнаты, цель, особенности) клиентской
  эвристикой — в проде это возьмёт на себя модель Claude через API.
- **Инвестиционный калькулятор (вид «Калькулятор инвестора»)** — выбор
  объекта, цена покупки и меблировка, переключатель модели монетизации
  (долгосрок / посуточно / гибрид), слайдер горизонта владения (1–10 лет),
  налог и комиссия управления. Справа — живые метрики (денежный поток, IRR,
  окупаемость), график капитализации с накопленной арендой и текстовый
  вердикт ИИ с рекомендацией модели монетизации.
- **Аналитика районов (вид «Аналитика районов»)** — агрегированные
  показатели по районам каталога (цена за м², Cap Rate, тренд цены) плюс
  сравнительная карточка рынков.
- **Панель агента (вид «Панель агента»)** — форма добавления объекта
  (название, район, комнаты, площадь, цена, описание, теги-особенности,
  допущения для доходности). Новый объект сразу появляется в поиске,
  калькуляторе и аналитике; хранится в `localStorage` браузера — реального
  бэкенда в прототипе нет.
- **Валюта и закладки** — переключатель USD/₾ GEL в сайдбаре меняет акцент
  цены по всему сайту; значок закладки на карточках сохраняет понравившиеся
  объекты (тоже в `localStorage`) и питает фильтр «Избранное».

## Технологии

Один файл `index.html`: HTML + CSS-переменные (с поддержкой светлой и
тёмной темы) + ванильный JS, без сборки и зависимостей. Шрифты — Epilogue,
Manrope, JetBrains Mono и иконки Material Symbols Outlined (Google Fonts).
