# Свайп квартир

Приложение для подбора арендных квартир: сначала пользователь отвечает на несколько
вопросов (бюджет, срок аренды, район, желаемая площадь), а затем просматривает
подходящие варианты в формате свайп-карточек — вправо, если квартира понравилась,
влево, если нет. В конце показывается список понравившихся вариантов.

## Стек

- React + TypeScript
- Vite
- framer-motion (свайп-жесты и анимации)

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура

- `src/data/apartments.ts` — мок-данные квартир
- `src/utils/filterApartments.ts` — фильтрация квартир по ответам анкеты
- `src/components/Onboarding.tsx` — анкета из 4 шагов
- `src/components/SwipeDeck.tsx` / `ApartmentCard.tsx` — стопка карточек и карточка квартиры
- `src/components/ResultsScreen.tsx` — список понравившихся квартир
